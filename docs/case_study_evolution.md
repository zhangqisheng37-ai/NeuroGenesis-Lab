# 案例研究：演化动力学分析

NeuroGenesis Lab 的核心特性之一是其基于能量经济的演化系统。本案例研究将探讨在长程仿真中观察到的演化动力学现象。

## 1. 实验设置

我们使用 `experiment_stable.toml` 配置运行了一个 500 ticks 的长程实验。该配置启用了自适应衰减和繁殖机制，以防止种群崩溃或爆炸。

```bash
python -m neurogenesis_lab run --config experiments/experiment_stable.toml --visualize --async-log --log-buffer-size 512
```

建议在运行前执行：

```bash
python -m neurogenesis_lab info
```

确认 `Rust Core: available` 后再进行性能相关对照实验。

## 2. 观察到的现象

### 2.1 种群数量的动态平衡

在实验初期，种群数量可能会因为初始能量较高而迅速增长。然而，随着神经元密度的增加，自适应衰减机制（`adaptive_decay`）会提高能量消耗率，同时自适应繁殖机制（`adaptive_reproduction`）会增加繁殖成本。

这导致种群数量在达到一个峰值后开始下降，最终在一个动态平衡区间内波动（通常在 20-60 之间）。这种负反馈机制有效地防止了种群爆炸。

### 2.2 能量分布的演化

通过观察能量分布直方图，我们可以发现：
- **初期**：能量分布较为集中，大多数神经元能量相近。
- **中期**：能量分布开始分化，出现"富"神经元和"穷"神经元。
- **后期**：由于能量上限（`energy_cap`）的限制，"富"神经元的能量被限制在 5.0 以内，防止了极端的不平等。

### 2.3 空间聚类与拓扑演化

在启用了空间连接（`spatial_radius`）的实验中，我们观察到明显的空间聚类现象。
- 神经元倾向于在母体附近繁殖（高斯扰动）。
- 距离较近的神经元更容易建立突触连接。
- 随着时间的推移，网络形成了几个密集的局部簇，这些簇之间通过少数长程连接相连，呈现出"小世界"网络的特征。

## 3. 结论

NeuroGenesis Lab 的演化系统能够模拟出复杂的生态动力学。自适应机制是维持长程稳定性的关键，而空间约束则促进了网络拓扑结构的涌现。这些现象为研究人工生命和自组织系统提供了有价值的参考。
