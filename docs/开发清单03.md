## 三、任务拆分（按优先级）

### P0：激活动力学闭环（必须先做）已完成

目标：解决“0 放电 / 0 传播”。

任务：
- 增强放电可达性：提供一套默认可放电参数组合（阈值、输入增益、基础电流三者联调）。
- 增加背景驱动：支持可配置 `background_current` 或 `spontaneous_spike_rate`。
- 调整输入到电位映射：将 `receive()` 能量增益与 `update()` 电流贡献关系显式化，避免输入事件“只加能量不驱动放电”。
- 增加运行期保护：若连续 N tick 零放电，给出 warning（而非静默失败）。

验收：
- 默认 `run` 在 100 ticks 内 `total_spikes > 0` 且 `total_propagations > 0`。
- 对照同 seed，多次运行关键指标可复现（允许浮点微差）。

---

### P1：打通完整配置链路（TOML → SimConfig → 引擎）（已完成）

目标：让配置真正可控且符合文档。

任务：
- 完整解析 `[simulation] [neuron] [network] [evolution] [evolution.fitness_weights]`。
- CLI 覆盖策略明确：命令行 > TOML > 默认值，并记录最终生效配置。
- `cmd_run` 构建网络时，显式透传 `energy_decay / reproduction_share / corpse_ttl / scavenger_radius / input_current_scale / move_cost / congestion_penalty / min_neurons` 等参数。
- 创建单元测试覆盖配置映射和优先级。

验收：
- 使用 `config.toml` 能真实改变仿真行为。
- 新增测试：配置映射与 CLI 覆盖测试通过。

---

### P2：统一实验语义与文档口径（已完成）

目标：消除“文档说一套、输出是另一套”。

任务：
- 统一 `schema_version` 文档示例，修正 `docs/metrics.md` 与代码版本一致。
- 明确事件字段语义（`src_id`/目标路由语义）并补充一段时序示例，避免误解。
- 在 `quickstart` 补充“如何判断实验是否有效激活”的检查项（如 spikes、propagation、alive 曲线）。

验收：
- 文档示例可直接复现实验输出。
- 新用户按文档可在 10 分钟内跑出“非零放电”的最小实验。

---

### P3：引擎一致性与可比性（原始 vs 向量化）（已完成）

目标：建立可比较实验基线。

任务：
- 约定统一对照配置（同 seed、同初始规模、同连接规则）。
- 增加一致性测试：关注统计口径一致（alive、spike 趋势、能量趋势），不要求逐 tick 全等。
- 输出 `benchmark` 结果时增加可比性说明（模型、参数、数据口径）。

验收：
- 新增一致性测试通过。
- benchmark 输出可明确解释“可比项/不可比项”。

### P4：可观测性与输出治理（已完成）

目标：支持长程实验与批量实验。

任务：
- 增加 `log_interval` 控制日志采样频率。
- 支持 `.jsonl.gz` 压缩输出（可选）。
- 增加轮转策略（如 `max_file_size`）或分段输出，防止长程 run 文件过大。

验收：
- 500+ ticks 长程实验输出可控，且分析脚本可正常读取。

---

### P5：回归与质量闸门升级（已完成）

目标：把风险前移到 CI/本地测试阶段。

任务：
