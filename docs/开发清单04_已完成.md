## 九、风险预警

### 新增风险

1. **可视化性能开销**：实时绘图可能拖慢仿真速度，需要异步更新机制。
2. **持久化文件体积**：大规模网络 checkpoint 可能达到 GB 级别，需要压缩。
3. **学习引擎内存泄漏**：规则库无限增长可能导致内存溢出，需要淘汰机制。
4. **空间系统复杂度**：空间连接可能导致网络过于稠密，需要度数限制。

### 缓解措施

1. 可视化使用独立进程，通过队列通信。
2. Checkpoint 使用 gzip 压缩，支持增量保存。
3. 规则库设置容量上限，使用 LRU 淘汰策略。
4. 空间连接增加 `max_links_per_neuron` 参数。
