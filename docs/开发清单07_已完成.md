# 第七阶段开发清单：工程基础设施完善与双引擎功能对齐 (Phase 7)

## 1. 当前项目现状分析

> 注：本节用于记录 Phase 7 启动时的问题背景；其中列出的差异项已在后续任务中逐步修复，当前事实请以 README/parameters/architecture/metrics 等主文档为准。

在完成前六个阶段的开发后（基础网络、进化算法、混合学习引擎、长程稳定与可视化、Rust 混合架构、代码质量治理），NeuroGenesis Lab 已成为一个**功能完整、架构清晰、测试充分**的神经进化仿真研究平台。

**当前代码基线**：v0.6.0，347 个测试用例全部通过，总覆盖率 92.61%，源代码约 6,500 行。

但在工程基础设施和引擎功能对齐方面，仍存在以下结构性短板：

1. **CI/CD 管道不完整**：仅有 Rust 扩展构建 / 运行时检查两条工作流，**缺少 Python 测试、lint、覆盖率的 CI 自动化**，回归质量依赖手动执行 `pytest`。
2. **版本号不一致**：曾出现 `pyproject.toml` / `__version__` / README 与阶段文档口径不同步，版本管理混乱。
3. **双引擎功能严重不对称**：`VectorizedNetwork` 相比 `Network` **缺少**尸体回收系统、自适应衰减/繁殖机制、多模型支持（仅 LIF，无 Izhikevich/AdEx）、记忆/学习集成、checkpoint 持久化。同一实验在两个引擎下的演化行为差距显著。
4. **CLI 模块依然臃肿**：`__main__.py` 仍为 732 行，是项目内最大的单文件；虽然 P0 已拆分子方法，但所有 CLI 命令、配置构建、仿真驱动逻辑依然挤在同一模块内。
5. **缺少 API 文档生成**：Phase 6 已完成 80%+ 的 docstring 覆盖，但无自动文档生成工具（Sphinx/mkdocs），开发者获取 API 信息仍需手读源码。
6. **项目发布准备欠缺**：无 `py.typed` 标记（PEP 561）、无 `LICENSE` 文件、无 `CONTRIBUTING.md`、无 `conftest.py` 共享测试夹具，离正式开源发布存在差距。
7. **类型标注松散**：`vectorized.py` 的 `_resolve_neuron_index(src_id: Any)`、`visualization.py` 的 `network: Any`、`learning.py` 的 `callable` 小写标注等弱类型残留。
8. **README / docs 信息滞后**：开发路线图阶段六标记为 `[ ]` 未完成，但实际 P0-P6 全部已交付；风险清单仍为 v0.4.x 口径。

## 2. 第七阶段核心目标

本阶段的核心目标是**工程基础设施完善与双引擎功能对齐**，使项目从"研究原型"向"可发布的开源项目"迈进，同时消除双引擎间的功能差距。

- **目标 1**：建立完整的 CI/CD 管道（Python 测试 + lint + 覆盖率 + 自动发布）。

- **目标 4**：将 `__main__.py` 拆分为 `cli/` 子包，降低模块复杂度。
- **目标 5**：引入自动 API 文档生成（mkdocs/Sphinx）。
- **目标 6**：完善项目发布基础设施（License、py.typed、CONTRIBUTING、conftest）。
- **目标 7**：消除弱类型标注，启用 mypy/pyright strict 模式。
- **目标 8**：全面同步 README / docs / 路线图与代码实际状态。

8. **发布就绪**：项目根目录具备 `LICENSE`、`CONTRIBUTING.md`、`py.typed`，README 含徽章。

## 7. 风险预警

| 风险 | 影响 | 缓解措施 |
| ---- | ---- | -------- |
| VectorizedNetwork 多模型向量化引入分支过多，性能退化 | tick 耗时增加 | 使用 `model_type` 掩码分组计算，基准测试持续对比 |
| CLI 拆分导致导入路径变化 | 外部脚本/文档中的导入路径失效 | `__main__.py` 保留 fallback 导入兼容，废弃旧路径时发出 DeprecationWarning |
| mypy strict 模式暴露大量隐式类型问题 | 修复工作量超预期 | 分模块逐步启用，先完成 `protocols` / `config` / `encoding`，再推进核心模块 |
| 双引擎尸体回收/自适应机制对齐验证困难 | 统计对比结论不可靠 | 使用固定 seed + 500 ticks 长程运行，对比种群大小、能量均值、出生/死亡计数的时间序列趋势 |
| mkdocs 插件与 Python 3.14 兼容性 | 文档构建失败 | 文档构建 CI 固定使用 Python 3.12，仿真测试覆盖 3.10~3.14 |
| Codecov 令牌配置失败 | 覆盖率趋势无法跟踪 | 先使用 GitHub Actions Job Summary 内嵌报告作为备选 |
