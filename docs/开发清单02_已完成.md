工程任务拆分清单 02（Python）

> 历史快照说明：本文档为阶段性任务记录，不作为当前版本与参数真值来源；请以 README / parameters / architecture / metrics 为准。

适用范围：在《开发清单01_已完成.md》基础上，进入“稳定化 + 可研究化 + 可扩展化”阶段。

总目标：
- 从“可运行原型”升级到“可复现实验平台”。
- 强化关键行为正确性（spike/emit/PE/繁殖/死亡）的可验证性。
- 让后续算法迭代（学习、演化、可视化）有稳定工程底座。

---

0. 阶段启动与基线冻结

目标：建立可对比的起点，避免后续改动失控。

任务：
- 固化当前基线：记录当前 `pytest` 通过状态、关键示例输出样本、默认配置。
- 新建 `CHANGELOG`（可选）记录阶段内行为变化（不是只记录代码改动）。
- 为 `jsonl` 输出加 `schema_version` 字段（兼容未来格式升级）。

验收：
- 能明确回答“与清单02启动时相比，行为变化了什么”。

---

1. 仿真核心稳定化（时序/动力学/复现）

目标：保证网络仿真在时间语义和数值行为上稳定可信。

任务：
- 统一事件时间语义：明确“输入事件时间”“当前 tick”“传播 delay”三者关系，并写入文档。
- 参数可控化：为输入电流缩放、阈值、衰减、移动成本提供集中配置入口。
- 复现能力：统一随机种子入口，覆盖 `random` 调用路径。
- 防异常：增加边界保护（NaN/Inf、负延迟、极端参数）并给出失败提示。

验收：
- 同一 seed + 同一配置，多次运行关键指标一致（允许浮点微小误差）。
- 在极端参数下不会崩溃，能返回可诊断错误信息。

---

2. 测试体系升级（从“能跑”到“能保真”）

目标：形成分层测试，保障回归质量。

任务：
- 单元测试：覆盖 `encoding/neuron/network/learning` 的核心分支和边界。
- 行为测试：新增“放电可触发传播”“PE 随重复输入下降趋势”“繁殖-死亡平衡”断言。
- 回归测试：固定 2~3 组标准输入，校验关键 `jsonl` 字段存在且语义正确。
- 失败可读性：断言信息改为“带上下文的失败说明”。

验收：
- `pytest` 覆盖率达到可接受阈值（建议先到 70%+，后续提升）。
- 关键行为回归可在 CI/本地一键发现。

---

3. 可观测性 2.0（研究友好）

目标：输出可直接用于实验分析与可视化的数据。

任务：
- 统一指标字典：区分 `network_metrics / neuron_metrics / learning_metrics`。
- 增加趋势指标：PE 滑动均值、有效传播率、活跃神经元比例、出生/死亡速率。
- Debug 增强：支持按神经元类型或条件过滤跟踪。
- 输出管理：按实验编号自动分目录，防止覆盖历史结果。

验收：
- 任意一次实验都能追溯：配置、过程指标、最终摘要三件套齐全。

---

4. 学习引擎进阶（从查表到可组合规则）

目标：把“能答题”推进到“可解释推理”。

任务：
- RuleStore 增加规则置信度与支持度统计。
- RuleComposer 增加多规则冲突处理（优先级或打分策略）。
- 引入更丰富样本（不只加法），验证泛化与失败模式。
- 输出解释：每次推理给出“命中了哪些规则”。

验收：
- 对未见过的简单样本可给出可解释结果或可信的 unknown。
- 推理日志可复盘“为什么得到这个答案”。

---

5. 演化系统进阶（可控而非失控）

目标：让演化过程可调参、可解释、可稳定。

任务：
- 明确 fitness 构成：传播贡献、能耗效率、预测命中等。
- 复制/变异策略可配置：变异幅度、能量分配、代际节奏。
- 生态约束：资源预算、连接上限、局部拥塞惩罚。
- 尸体回收机制增强：回收半径、衰减规则、参数融合策略可配置。

验收：
- 长时间运行时，网络规模在可控区间波动，不出现单向爆炸或快速灭绝。
- 参数分布变化可被日志清晰观测。

---

6. 工程化与使用体验

目标：降低使用门槛，支持批量实验。

任务：
- 提供统一 CLI（如 `python -m neurogenesis_lab ...`）管理训练/仿真/导出。
- 配置文件化（yaml/toml 二选一），支持命令行覆盖关键参数。
- 增加实验脚本模板（最小实验、对照实验、长程演化实验）。
- 文档补齐：快速开始、参数说明、常见问题。

验收：
- 新用户按文档 10 分钟内可跑通一个完整实验并拿到 `jsonl`。

---

7. 核心引擎重构（性能专项）

目标：引入 NumPy 向量化，解决 Python 循环性能瓶颈，支持万级神经元仿真。

任务：
- 引入 NumPy 依赖。
- Neuron 状态向量化（v, u, energy 等存为矩阵）。
- 空间索引优化（k-d tree 或网格）。
- 保持接口兼容性，确保单元测试通过。

验收：
- 相同规模网络仿真速度提升 10x 以上。
