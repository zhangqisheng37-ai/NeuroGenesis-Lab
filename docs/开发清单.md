5. 学习引擎 Learning（先实现"能答题"，再谈"推理"）—— 已完成

这里拆成 A/B 两层，别一口吃成胖子。

5A. 序列记忆 + 模式抽取（最小可用）

 MemoryBank：存训练序列（token 序列）

 PatternMiner：

 抽取模板：如 a op b = c

 建立映射表：(a, op, b) -> c（先做加法）

 QueryEngine：

 输入 "1+3=?" → 查表输出 "4"（若已有）

 若无：返回 unknown/置信度低

验收： 喂 "1+1=2","1+2=3" 能正确回答训练集问题

5B. 规则发现与归纳（通过时空信号发现结构规律）

重要说明：
- 单从 1+1=2, 1+2=3 推不出 3=1+1+1
- 这不是类似 "++草=草+草=植物"，"++化=花+花=植物" 的字形比较
- 真正能发现的是：通过时空中的信号传播模式，归纳出结构性规律
- 类比：从"草"和"花"的共现模式中发现"艹"这个偏旁的结构意义
- 人类思考本质：通过时空中信号去发现规则、总结规律
- 推理时：根据已发现的规则去耦合组合

 RuleDiscovery：
 
 从时空传播模式中提取结构特征（而非简单的符号映射）
 
 识别共现模式、传播路径、激活序列
 
 归纳出可复用的结构规律（如：偏旁、运算符、后继关系）

 RuleStore：存储已发现的规律

 规律类型：结构规律（如偏旁）、运算规律（如加法）、后继规律

 RuleComposer：推理时根据已发现规则进行耦合

 输入问题 → 匹配适用规则 → 组合应用 → 输出结果

验收： 能从多个样本的时空传播模式中发现共性规律，并在新问题中应用这些规律

6. 演化系统 Evolution —— 已完成

目标：满足需求第2步：复制/遗传/变异/能量/熵增/吞噬

 Fitness 定义（先别玄学）：

 参与有效传播 + 预测命中加分

 复制机制：

 if energy > threshold: reproduce()

 遗传：复制参数（传播阈值、移动倾向、初始统计先验）

 变异：扰动参数

 熵增/防膨胀：

 全网能量衰减

 neuron 数/连接数上限

 死亡与吞噬：

 死亡后产出 Corpse(params, energy)

 附近 neuron 可拾取融合（能量 + 参数融合）

验收： 网络在持续输入事件时能稳定在一个规模区间，不会无限膨胀，且参数分布随时间变化
