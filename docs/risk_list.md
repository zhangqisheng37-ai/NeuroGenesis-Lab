# 下一阶段风险清单（v0.4.x）

> 更新时间：2026-02-22
>
> 本清单基于阶段四当前实现状态：长程稳定性、实时可视化、学习引擎集成、空间系统均已完成。

---

## 🔴 高优先级风险（仍需处理）

### R1: 激活动力学对外部输入强依赖

**现象**: 在弱刺激配置下，放电/传播仍可能偏低。
**影响**: 实验有效窗口缩短，统计不稳定。
**建议**:

1. 引入 `background_current` 或 `spontaneous_spike_rate` 参数
2. 提供“低激活自动告警阈值”可配置化（而非固定提示）
3. 增加官方“激活态配置模板”

### R2: 能量经济仍可能出现双极化（爆发/衰亡） ✅ 已缓解

**状态**: v0.4.0 已引入自适应衰减、能量上限和濒危保护机制，500+ ticks 实验已能稳定运行。
**建议**: 持续观察更长程（2000+ ticks）实验中的能量分布。

### R3: 向量化与原始引擎仍为”统计一致”而非”机制一致” ✅ 已阶段性缓解

**现象**: 已建立统计可比测试，但模型细节尚未完全对齐。
**进展**: v0.3.1 已统一双引擎接口（`TickSnapshot` / `EngineSummary` / `SimEngine` 协议），返回字段完全一致。
**影响**: 机制级结论仍需谨慎外推，但已具备延迟事件路由对齐能力。
**建议**:

1. 分阶段引入 Izh/AdEx 向量化实现
2. 在 benchmark 中持续标注”可比项/不可比项”
3. 增加更多趋势对照（PE、活跃率、能量分布）

## 🟡 中优先级风险

**状态**: v0.4.0 已实现 `AutoLearner` 包装类，自动从仿真流中提取样本并更新规则，并提供预测奖励。

**状态**: ✅ 已修复。
**进展**: 已补齐 `main()` 入口链路下的 `run`/`benchmark` 冒烟测试，并覆盖 checkpoint 文件落盘校验。
**建议**: 将 CLI 冒烟测试纳入发布前检查清单。
